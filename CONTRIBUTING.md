# Contributing

This is a personal learning project, but suggestions and improvements are welcome!

## How to contribute

1. Fork the repository
2. Create a new branch: `git checkout -b feature/your-improvement`
3. Make your changes
4. Push and open a Pull Request

## Ideas for contributions

- Add more attack types (CSRF, Command Injection, File Upload)
- Add Snort/Suricata detection rules for each attack
- Add automated setup scripts
- Improve the findings report with more analysis

## Code of Conduct

All contributions must be ethical and educational in nature.  
Do not add content that facilitates harm to real systems.
